# ♟️ Ajedrez Online Multijugador

Un juego de ajedrez interactivo en tiempo real donde dos jugadores pueden enfrentarse desde distintos navegadores. Construido con tecnología WebSockets para garantizar una sincronización instantánea de los movimientos y persistencia de datos.

## 🚀 Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript Vanilla
* **Backend:** Node.js, Express.js
* **Base de Datos:** MongoDB
* **Tiempo Real:** Socket.io
* **Herramientas:** ESLint, Stylelint, HTMLHint

## ⚙️ Instalación y Uso Local

Sigue estos pasos para levantar el servidor en tu máquina:

1. Instala las dependencias del proyecto:
   `npm install`

2. Inicia el servidor:
   `node app.js`

3. Abre tu navegador e ingresa a:
   `http://localhost:80` *(o el puerto que estés utilizando)*
